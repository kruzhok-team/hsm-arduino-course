# Введение в программирование машин состояний (ПРИМС) в Arduino

Образовательный курс для начинающих по знакомству с программированием
расширенных иерархических машин состояний (ПРИМС) для контроллеров Arduino с
использованием среды Cyberiada IDE.

Авторы курса: ![Алексей Федосеев](mailto:aleksey@fedoseev.net) и ![Анита Ходова](mailto:anita-hodova@inbox.ru).

Курс состоит из введения, 8 занятий, промежуточного и финального теста:

* [Устройство курса](00-course-structure.md)
* [Занятие 1. Введение в цифровую электронику и микроконтроллеры](01-digital-electronics.md)
* [Занятие 2. Машина состояний для управления светофором на Arduino](02-traffic-light-sm.md)
* [Занятие 3. Основы программирования машин состояний: состояния и события в
  программе](03-states-and-events.md)
* [Занятие 4. Язык программирования машин состояний (ПРИМС) для реальных
  устройств](04-hsm-language.md) и [промежуточный тест курса](04-1-intermediate-test.md).
* [Занятие 5. Управление с использованием датчиков: аналоговые и цифровые
  порты](05-sensors.md)
* [Занятие 6. Устройство микроконтроллера. Язык С++ для программирования
  микроконтроллеров](06-mcu-and-cpp.md)
* [Занятие 7. Программирование Arduino на С++](07-arduino-cpp.md)
* [Занятие 8. Управление внешними устройствами: использование двигателей и
  реле](08-motors-and-relays.md) и [итоговый тест курса](08-1-final-test.md).
